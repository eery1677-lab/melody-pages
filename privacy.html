1. 이 앱을 쓰는 사람

이 앱은 유튜브 채널 「비전 멜로디」 운영자가 자기 컴퓨터에서 직접 쓰는 개인용 도구입니다. 다른 사람의 구글 계정을 연결하지 않으며, 일반 사용자에게 제공하는 서비스가 아닙니다. 연결되는 계정은 운영자 본인의 구글 계정뿐입니다.

2. 접근하는 구글 데이터와 쓰는 목적

  • 유튜브 계정·채널 정보: 연결된 채널이 맞는지 확인합니다.
  • 유튜브 영상 업로드·수정·댓글: 운영자가 승인한 영상을 본인 채널에 올리고, 영상 설명을 고치고, 고정 댓글을 답니다.
  • 유튜브 분석(조회·시청 시간·구독 증감): 본인 채널의 성과를 읽어 주간 요약을 만듭니다.
  • 구글 드라이브(앱이 만든 파일만): 만든 곡 파일을 운영자 본인의 드라이브에 복사해 백업합니다. 드라이브의 다른 파일은 열어 보지 않습니다.

위 목적 외에는 쓰지 않습니다.

3. 데이터의 보관

연결 정보(접근 열쇠)와 읽어 온 통계는 운영자의 컴퓨터에만 저장됩니다. 외부 서버로 보내 보관하지 않습니다. 통계 요약은 운영자 본인에게만 전달됩니다.

4. 제3자 제공

구글 계정 데이터를 판매하거나 광고에 쓰거나 다른 사람·회사에 제공하지 않습니다.

5. 구글 API 서비스 사용자 데이터 정책

이 앱이 구글 API로 받은 정보의 사용과 다른 앱으로의 전달은 Google API 서비스 사용자 데이터 정책의 제한적 사용 요건을 포함해 이 정책을 따릅니다.

유튜브 API 서비스를 쓰므로 유튜브 서비스 약관과 구글 개인정보처리방침이 함께 적용됩니다.

6. 연결 해제와 삭제

  • 구글 계정의 서드 파티 앱 및 서비스 화면에서 언제든 이 앱의 접근 권한을 해제할 수 있습니다.
  • 앱 안의 「연결 해제」 기능을 쓰면 저장된 접근 열쇠가 지워집니다.
  • 이 앱이 구글 드라이브에 만든 백업 폴더는 운영자가 드라이브에서 직접 삭제할 수 있습니다.

English summary

Vision Melody Automation is a private tool used only by the operator of the YouTube channel "Vision Melody", running on the operator's own computer. It connects only the operator's own Google account.

  • YouTube: uploads videos the operator has approved to the operator's own channel, edits descriptions and pinned comments, and reads the channel's own analytics to build a weekly summary.
  • Google Drive (drive.file scope only): copies the operator's generated song files to the operator's own Drive as a backup. It cannot see other files in Drive.
  • Credentials and data stay on the operator's computer. Google user data is not sold, shared with third parties, or used for advertising.
  • The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The YouTube Terms of Service and the Google Privacy Policy also apply.
  • Access can be revoked at any time at myaccount.google.com/permissions.
